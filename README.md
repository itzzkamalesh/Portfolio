A premium, glassmorphic personal portfolio designed from the ground up to showcase academic machine learning models, natural language processing pipelines, and data systems. Developed with an elegant **Obsidian Black**, **Neon Gold**, and **Electric Blue** color palette.

---

## 🎯 Key Design Features

*   **✨ Minimalist Hero Section**: A clean, balanced layout designed to present your profile, subtitle, and resume download clearly to recruiters.
*   **🧠 Golden Matrix Glow**: The technical skill cards feature responsive custom gold border transitions and depth shadow glows when hovered over.
*   **🔮 3D Education Cards**: Fully interactive education blocks that track mouse movement in real-time to simulate physical 3D spatial tilt.
*   **🎠 Endless Auto Slider**: Certificates slide horizontally on a continuous, autoplaying loop. Hovering over a card dynamically pauses the cycle so the credential links can be verified.
*   **📱 Fluid Mobile Responsiveness**: Grid columns use modern CSS layout bounds (`minmax(280px, 1fr)`) to scale down cleanly on small screens without breaking layout borders.
