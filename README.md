# Kamalesh R - AI & ML Engineer Portfolio

An elegant, high-fidelity personal portfolio website designed for showcasing academic engineering achievements, skills, and professional certifications. Built using native web technologies with a modern, glassmorphic layout featuring an Obsidian Black, Neon Gold, and Electric Blue design system.

## 🚀 Live Demo & Visual Highlights
- **Simple, Responsive Hero Section**: Clean typographic structure with straightforward Call to Actions (CTAs).
- **Interactive Technical Matrix**: Highlighted skillset cards featuring custom gold glows upon hover.
- **3D Interactive Hover Cards**: Education cards respond with physical spatial tilt and depth based on mouse movements.
- **Automatic Certificate Carousel**: Smooth automatic horizontal sliding slideshow showcasing credential placeholders with transition scaling.
- **Unified Contact Area**: Clean link grids displaying optimized, long-URL-safe direct social cards (LinkedIn, GitHub, Email, Phone).
