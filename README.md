## 🎨 Interactive Micro-Animations

*   **✨ Refined Hero Presentation**: A simple, clean, and highly readable landing card designed to instantly present key credentials and download pathways.
*   **🧠 Golden Matrix Hover Glow**: Technical skill cards feature responsive custom gold border transitions and depth shadow glows when hovered over.
*   **🔮 3D Education Cards**: Fully interactive education blocks that track mouse movement in real-time to simulate physical 3D spatial tilt.
*   **🎠 Endless Auto Slider**: Certificates slide horizontally on a continuous, autoplaying loop. Hovering over a card dynamically pauses the cycle so the credential links can be verified.
*   **📱 Fluid Mobile Responsiveness**: Grid columns use modern CSS layout bounds (`minmax(280px, 1fr)`) to scale down cleanly on small screens without breaking layout borders.
